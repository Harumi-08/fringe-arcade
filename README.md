# 邊緣人大全｜Fringe Arcade

一個人也能開桌的手機優先網頁遊樂場。從朋友試玩的小遊戲集合，逐步加入遊玩紀錄、收藏與 NPC 互動，再延伸成可以坐下休息的咖啡廳。

**線上體驗：** https://fringe-arcade.sunny-haru.chatgpt.site/

本文整理截至 **2026 年 10 月 4 日** 的研發過程。功能狀態以目前程式、Git 提交和已完成的部署紀錄為依據；日期以臺灣時間為主。本儲存庫包含研發紀錄與目前版本的完整程式碼；公開副本已移除實際收款連結及正式網站綁定設定。

## 專案起點

開發動機是「覺得有趣」，希望找不到朋友陪玩、或想自己待著的人，也能隨時玩團體遊戲。先讓朋友實際試玩，再根據回饋調整。自願支持開發的咖啡錢入口是在後續加入，遊戲保持免費。

使用者負責產品構想、功能取捨、試玩回饋和宣傳文案；Codex 協助實作、程式檢查、測試與部署。NPC 對話使用預先撰寫的分支內容，並未接入生成式 AI 聊天服務。

## 已完成的功能

### 20 款遊戲與趣味互動

自己剪刀石頭布、男生女生配、大老二、網頁小恐龍、終極密碼、群組聊天室、一個人的躲貓貓、邊緣人抽鬼牌、自己比手畫腳、一個人的狼人殺、真心話大冒險、井字遊戲、五子棋、踩地雷、2048、孤獨色牌、邊緣人轉盤、聚餐座位模擬器、已讀挑戰與朋友召喚池。

這些功能包含休閒遊戲與趣味模擬，部分採簡化規則。「孤獨色牌」是接顏色與數字的簡化玩法；本專案不是官方 UNO 產品。

### 遊玩成長與收藏

- 等級、成就，以及可選稱號、牌背、小恐龍配色與聊天室頭像。
- 各遊戲完成次數；適用遊戲記錄勝負、連勝、分數或難度。
- 剪刀石頭布分開記錄左右手勝場與平手；它描述玩家的選擇結果，不代表左右手的能力差異。
- 自訂挑戰：同時最多三項，從建立後開始累積，完成時一次性獲得 30 點。
- 七種朋友卡圖鑑，包含稀有度與重複抽到的次數。
- 戰績圖片下載、支援瀏覽器的原生圖片分享，以及戰績文字與網址複製。
- 阿電、小花、老王各有選牌偏好與預設對白。

### 邊緣人咖啡廳

- 座位：靠窗、吧台、角落。
- 免費虛擬飲料：美式、茶、拿鐵、奶茶、熱可可、白開水。
- 安靜坐坐、選話題聊天與 10／25／45 分鐘計時器。
- 累積來店三天後解鎖熟客小故事。
- 玩家主動授權定位，或手動搜尋城市，取得當地溫度、天氣與日夜資訊。
- 天氣區配色和靠窗對白隨資料變化；無法查詢時顯示錯誤狀態，不假裝成固定雨天。
- 合成背景聲：窗外小雨、輕風吹過、緩慢海浪、柔和棕噪音、細緻白噪音。可調整音量並記住偏好，離開咖啡廳停止播放。
- 所有中文介面使用繁體字；外部回傳的簡體地名會轉換後顯示。

### 自願支持與訪客統計

- 首頁及遊戲結束畫面提供咖啡贊助入口，不影響免費遊玩；付款連結期限到後停用入口。
- 自 2026 年 10 月 2 日開始記錄每日及累積瀏覽次數、匿名瀏覽器訪客估計、遊戲開啟、咖啡廳使用與贊助點擊次數。
- 全站統計集中儲存於資料庫，未提供公開查詢端點；目前透過網站管理工具查看，尚未實作獨立的站內管理儀表板。
- 贊助點擊不能代表付款成功，遊戲開啟次數也不能代表完成局數。

## 技術演進

初版以原生 HTML、CSS、JavaScript 實作，遊戲介面使用 DOM 與 Canvas；手機版採響應式排列。等級、外觀、戰績、收藏及咖啡廳偏好仍儲存在瀏覽器 localStorage，沒有帳號同步。

加入全站統計後，部署改為 Cloudflare 相容的 ESM Worker。建置時將前端文字資產打包到 Worker，沿用原本遊戲功能；統計寫入 Cloudflare D1，透過 Drizzle schema 與版本化 migration 管理資料表。

| 模組 | 職責 |
| --- | --- |
| `app.js` | 遊戲、共用結算、等級與原始存檔。 |
| `features.js` | 細項戰績、挑戰、朋友圖鑑、分享卡、NPC 個性與支持入口。 |
| `cafe.js` | 咖啡廳、計時器、NPC 分支與天氣查詢。 |
| `cafe-sounds.js` | Web Audio 合成背景聲、音量與播放生命週期。 |
| `traditional.js` | 外部地名的簡體轉繁體字元轉換。 |
| `traffic.js` | 匿名瀏覽器識別碼及功能使用事件送出。 |
| `worker/index.mjs` | 提供前端資產，驗證並寫入統計事件。 |
| `db/schema.ts`、`drizzle/` | 全站統計資料結構與 migration。 |

外部天氣服務使用 Open-Meteo，城市資料來源為 GeoNames。背景聲使用 Web Audio 合成，並非現場環境錄音。

## 已執行的驗證與限制

已執行 JavaScript 語法檢查，以及具體流程的 Node／VM 模擬測試：

- 舊等級、外觀及主要存檔欄位沿用。
- 左右手勝負、分難度戰績、挑戰獎勵只發一次與連勝重設。
- 朋友重複收藏、抽卡次數與分享文字。
- 咖啡廳偏好、每日來店去重、計時暫停／重設與離開清理。
- 天氣分類、定位回傳資料處理、地名轉繁體。
- 統計重複事件去重、同瀏覽器訪客去重、瀏覽次數累積與輸入驗證；使用本機 SQLite 模擬資料庫。
- 聲音樣本數值、振幅上限、循環邊界、切換與離開時停止播放。

各版本完成部署後，確認平台回報成功；統計版本另確認正式資料庫資料表已建立。上述 VM／模擬測試不等同於完整瀏覽器端到端測試。手機定位授權、原生分享選單、音色主觀聽感及跨瀏覽器呈現，仍需實機測試。

目前沒有將所有臨時測試整理成儲存庫內可持續執行的測試套件，也尚未完成完整自動化 UI 測試。

## 資料與隱私界線

- 玩家進度只存在各自瀏覽器；清除網站資料或換裝置可能丟失。
- 全站統計使用隨機瀏覽器識別碼；伺服器保存其 SHA-256 雜湊，不記錄聊天文字、姓名或天氣定位。
- 同一人使用不同裝置、瀏覽器或清除資料，可能被當成不同訪客；統計不代表精確人數，也不能宣稱已排除所有機器流量。
- 定位座標會約略化後傳給天氣服務，不寫入遊戲存檔；手動選擇的城市會保存在裝置內。
- 收款頁網址、銀行資料、憑證與私密設定不包含在這份公開文件內。

## 開發心得

這個專案的主要迭代方式是「先提供能玩的版本 → 朋友實際使用 → 把具體回饋轉成小幅更新」。左右手勝率來自朋友的許願；等級用途、當地天氣與聲音調整則來自實際試玩。設計上持續保持免安裝、自由遊玩與可選互動，同時逐步補上存檔相容性、錯誤狀態和可驗證的使用統計。


## 本機執行與建置

前端原始碼位於 `dist/`，此專案直接編輯這些 HTML、CSS 與 JavaScript 檔案。

```sh
python3 -m http.server 8000 --directory dist
```

開啟 http://localhost:8000。遊戲與咖啡廳可在靜態伺服器執行；定位需要瀏覽器授權。靜態預覽沒有統計 API，無法集中累計訪客。

Worker 建置：

```sh
npm ci
node scripts/build-traffic.mjs
```

輸出為 `dist/server/index.js`。正式部署需自行設定 Cloudflare 相容的 Worker 與名為 `DB` 的 D1 綁定，並套用 `drizzle/` 的 SQL migration。本儲存庫不包含正式資料庫內容、服務憑證或既有 Sites 專案綁定。

公開副本的贊助入口預設停用；若自行部署，可在 `dist/features.js` 的 `coffeePayment` 設定自己的有效收款網址與期限。
